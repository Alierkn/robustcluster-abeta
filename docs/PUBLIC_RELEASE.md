# Public source snapshot

The GitHub repository is published at https://github.com/Alierkn/robustcluster-abeta from an audited tracked-file snapshot. It has a fresh public Git history. The earlier local development history is retained locally; historical commit IDs in run manifests therefore identify local provenance and need not resolve in the public repository. Numerical outputs and original manifests are not rewritten to simulate a different execution history.

## Included

New modular Python source, tests, configuration, workflow, figure/table outputs, report sources and final PDF, cited-reference register, audit records, and detector-review evidence. Historical successful, failed and blocked logs remain labelled as such. The selected report/QA manifests in `release_manifest.json` identify the current deliverable. Local runtime paths in historical manifests are provenance, not portable configuration.

## Excluded

Raw descriptor input, complete/partial FES files, supplied legacy script, publisher PDF, private correspondence, credentials, local provenance file, runtime environments, build caches and prior private Git history. The preserved legacy source remains local until redistribution rights are established. Every new implementation module is available in `src/robustcluster_abeta`; the code guide links to the separate VMD MCP and GROMACS MCP repositories.

## Verification boundary

Local tests and report compilation precede publication. GitHub Actions runs software tests independently after push; its actual status must be read from GitHub rather than inferred from local success. Report regeneration uses saved outputs. Re-execution of the scientific analyses requires authorized raw inputs and unresolved physical provenance. No new biological analyses were run during this editorial release.

Third-party excerpts retain notices in `LICENSES/`; see `THIRD_PARTY_NOTICES.md`. The cover includes the student's supplied academic details and institution seal. It does not imply institution or journal endorsement.
